# Clickable advancements

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_511733_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/511733.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Clickable advancements is a lightweight Minecraft mod which lets you click on the advancements in the chat to open the Advancement window, a must-have for every kitchen sink pack.

The mod allows players to easily find and navigate to advancements they gain, letting them explore the advancement progress more easily and helps them getting into those mods.

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
